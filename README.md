# Pages

Contiene las 3 unidades de negocio:

* `Distribeauty`
* `Redrejuvenece`
* `Newoman`

Cada uno con respectivo diseño y secciones correspondientes

Cuando pidan un requerimiento nuevo se implementará aquí y despúes implementar en producción.

Servirá tanto para implementar funcionalidades/diseño nuevas como para respaldo de páginas.

## Correr el proyecto

Para correr el proyecto se tiene que hacer lo siguiente:

```bash
cd <unidad>

pnpm install
pnpm dev
```
